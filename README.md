# DUO CUP

Турнир CS2 2×2 на Xplay. Ориентир — пятница, 13 ноября 2026, около 21:00 МСК. Старт вручную через панель.

## Запуск на ПК наблюдателя

1. Запустите `start.cmd` и оставьте окно открытым. Нужен Node.js 22 или новее.
2. Откройте [панель организатора](http://127.0.0.1:8787/control). Вставьте значение `admin` из файла `runtime/keys.json`. На первом запуске файл появится автоматически.
3. Если канал Twitch уже известен, вставьте ссылку на него и нажмите «Сохранить ссылку».
4. Проверьте, что в панели показано «Сайт синхронизирован». Опубликованная страница показывает последнюю синхронизированную сетку, даже когда ПК наблюдателя выключен.

## Подключение к матчу

1. В Steam откройте свойства CS2 → «Установленные файлы» → «Обзор». Скопируйте `runtime/gamestate_integration_duocup.cfg` в папку игры `game/csgo/cfg/`. Перезапустите CS2 после копирования.
2. На Xplay создайте персональный матч со стандартным соревновательным пресетом 5×5. Поставьте по два игрока на каждую сторону, отключите ботов и подключите пятого участника как наблюдателя. Проверьте подключение в тестовом лобби до эфира.
3. В панели выберите пару и нажмите «Вывести матч в эфир». Если игровые ники отличаются от составов, выберите, кто сейчас играет за CT. После привязки оверлей отслеживает смену сторон по игрокам. При подключении как наблюдатель появятся радар, таймер, нижние карточки и данные наблюдаемого игрока. Скопируйте свежий CFG и перезапустите CS2 после обновления конфига.
4. После матча подтвердите счёт **по картам** в порядке команд из панели. Например, `1 : 0` для BO1, `2 : 1` для BO3, `3 : 2` для BO5. Если GSI временно отключится, можно подтвердить результат по игровому табло или истории матча Xplay.

## OBS и Twitch

1. В OBS выберите «Коллекция сцен → Импорт». Для базового холста 3840×2160 импортируйте `obs/DUO-CUP-4K.json`, для холста 1920×1080 — `obs/DUO-CUP.json`. Обе коллекции содержат «Ожидание и перерыв» и «Матч CS2». Размер базового холста указан в «Настройки → Видео».
2. В сцене «Матч CS2» откройте свойства источника «CS2 · окно наблюдателя» и выберите запущенный CS2. В игре используйте оконный режим без рамки.
3. Проверьте звук CS2 и микрофон. При двух комментаторах добавьте источник звука приложения с голосовым чатом. Оставьте по одному источнику для каждого сигнала, чтобы избежать эха.
4. Подключите канал в настройках трансляции OBS. На время репетиции используйте локальную запись. Графика OBS загружается из локального сервиса и работает при выключенном Twitch.
5. Чтобы добавить задержку перед следующим эфиром, откройте в OBS «Настройки → Расширенные → Задержка потока», включите её и укажите длительность в секундах.

### Матчевая графика

Лента убийств берётся из CS2 вместе с игровым кадром. Скопируйте `obs/duocup_match_hud.cfg` в `game/csgo/cfg/` и выполните в консоли наблюдателя `exec duocup_match_hud`. Команда уберёт дублирующее табло и сдвинет ленту ниже счётчика живых. Положение ленты можно уточнить через `safezoney` по предпросмотру OBS. Для возврата игрового интерфейса используйте `cl_draw_only_deathnotices 0`.

Иллюстрации по умолчанию условные. Для портретов положите изображения PNG, JPEG или WebP в `runtime/hud-media/` и добавьте файл `runtime/hud-media.json`. Ключ — точный игровой ник. В режиме репетиции используйте папку `runtime/rehearsal/` вместо `runtime/`.

```json
{
  "ИгровойНик": {
    "portrait": "/hud-media/player.png",
    "camera": "https://vdo.ninja/?view=your-view-id&mute"
  },
  "teams": {
    "t1": { "logo": "/hud-media/team-1.png" }
  }
}
```

Укажите ссылку просмотра для камеры, если она доступна. Без камеры в этой рамке показывается портрет. После изменения файла обновите кэш источника «DUO CUP · графика матча» в OBS.

Изображения радара, данные карт и силуэты оружия извлечены из игровых ресурсов Valve. [Карты и радары](https://github.com/MurkyYT/cs2-map-icons), [иконки оружия](https://github.com/Juknum/counter-strike-icons).

## Проведение турнира

- «Начать турнир» публикует первый тур. Пары 1–8, 2–7, 3–6 и 4–5 составляются по порядку присланных команд.
- В отборе используется BO1. После завершения всех матчей тура нажмите «Сформировать следующий тур». Подбор минимизирует повторы, затем разницу в числе побед. При нечётной группе по счёту возможна пара с разными результатами.
- После трёх побед команда проходит дальше, после трёх поражений выбывает. Когда определятся четыре участника, полуфиналы заполнятся автоматически. Посев по числу поражений, при равенстве — по первоначальному порядку команд. Полуфиналы #1–#4 и #2–#3, серии BO3. Финал BO5.
- Статус «В эфире» отмечает выбранный матч. Остальные матчи можно проводить параллельно и отдельно подтверждать результаты.
- Текущее состояние хранится в `runtime/state.json`. Храните резервную копию этой папки между сессиями. Файлы `runtime/keys.json`, `runtime/publish.json` и локальный CFG содержат ключи.
